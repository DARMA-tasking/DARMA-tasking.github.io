{\ttfamily loc} is a standalone, communication-\/backend-\/agnostic library that answers one question for a set of migratable entities:\+ {\bfseries{which rank currently hosts entity X?}} It tracks entity registration and migration, caches resolutions, and keeps those caches coherent — all on top of the \href{https://github.com/DARMA-tasking/comm}{\texttt{{\ttfamily comm}}} communication abstraction, with no dependency on VT.

It is extracted from VT\textquotesingle{}s location manager ({\ttfamily vt/\+src/\+vt/\+topos/\+location}) and redesigned around {\ttfamily comm}\textquotesingle{}s {\ttfamily Communicator} concept.\hypertarget{md__2loc_2docs_2md_2overview_autotoc_md6}{}\doxysection{\texorpdfstring{Resolver, not router}{Resolver, not router}}\label{md__2loc_2docs_2md_2overview_autotoc_md6}
{\ttfamily loc} is a {\bfseries{resolver}}:\+ it tells you the node an entity lives on. It does {\itshape not} forward the entity\textquotesingle{}s own messages. Once {\ttfamily get\+Location} hands back a node, the embedder performs the actual send. This keeps {\ttfamily loc} free of message envelopes, epochs, and eager/\+rendezvous routing — the pieces most entangled with a specific runtime. (Message forwarding on top of {\ttfamily comm} is a possible later phase.)\hypertarget{md__2loc_2docs_2md_2overview_autotoc_md7}{}\doxysection{\texorpdfstring{Public API}{Public API}}\label{md__2loc_2docs_2md_2overview_autotoc_md7}
The one type you use is {\ttfamily \doxylink{structloc_1_1Coordinator}{loc::\+\+Coordinator}\texorpdfstring{$<$}{<}Entity\+ID, Comm\texorpdfstring{$>$}{>}}:\+


\begin{DoxyItemize}
\item {\ttfamily register\+Entity(id, home)} /\+ {\ttfamily entity\+Immigrated(id, home, from)} — an entity now lives on this rank.
\item {\ttfamily entity\+Emigrated(id, new\+\_\+node)} — an entity left this rank.
\item {\ttfamily unregister\+Entity(id)} — an entity no longer exists here.
\item {\ttfamily get\+Location(id, home, action)} — asynchronously resolve the hosting node; {\ttfamily action(node)} fires once known.
\item {\ttfamily entity\+Exists(id, home, action)} — asynchronously test existence; {\ttfamily action(exists, node)}.
\item {\ttfamily is\+Cached(id)}, {\ttfamily clear\+Cache()}, {\ttfamily this\+Node()}.
\end{DoxyItemize}
