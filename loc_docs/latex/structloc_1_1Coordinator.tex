\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Entity\+ID, typename Comm$>$\newline
struct loc::\+\+Coordinator$<$ Entity\+ID, Comm $>$}
Distributed location resolver for a set of migratable entities. 

A {\ttfamily \doxylink{structloc_1_1Coordinator}{Coordinator}} answers the question "{}which rank currently hosts entity X"{} and keeps that answer coherent as entities migrate. It is a {\itshape resolver} only:\+ it never forwards the entity\textquotesingle{}s own messages. Once a location is resolved the embedder performs the actual send.

Each entity has a fixed {\itshape home} rank (a deterministic function of its id, chosen by the embedder). The home holds the authoritative record; other ranks cache resolutions and are refreshed eagerly when the location changes.

All inter-\/rank traffic goes through the injected {\ttfamily Comm} (any type satisfying loc::\+\+Communicator):\+ the coordinator registers itself as a collective instance and issues point-\/to-\/point control messages via {\ttfamily Comm::\+send$<$\&method$>$}. Because registration is collective, every rank must construct its coordinator in the same order so instance handles line up.
