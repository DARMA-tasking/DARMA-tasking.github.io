struct vt::\+location::\+\+Loc\+Communicator$<$ Entity\+ID $>$}
Adapter satisfying loc::\+\+Communicator with VT objgroup messaging. 

The containing \doxylink{structvt_1_1location_1_1_entity_location_coord}{Entity\+Location\+Coord} is already a collectively-\/created objgroup, so its proxy is also the collective instance handle expected by loc. Control-\/plane RPCs are dispatched to the embedded loc coordinator.
