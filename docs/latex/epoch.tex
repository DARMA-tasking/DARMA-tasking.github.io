\doxysubsection{Epoch Manager }
\hypertarget{epoch}{}\label{epoch}\index{Epoch Manager@{Epoch Manager}}
Manage TD epochs.

The epoch manager component {\ttfamily \doxylink{structvt_1_1epoch_1_1_epoch_manip}{vt::\+epoch::\+\+Epoch\+Manip}}, accessed via {\ttfamily \doxylink{namespacevt_ad246530e523687095c567ccab203556a}{vt::\+the\+Epoch()}}, manages termination epochs that are allocated and deallocated as a program executes to encapsulate and order distributed work. The epoch manager controls the bits allocated for these along with scopes (distinct, collective strands of epoch bit allocation) for generating the bits. The epoch manager also allows inspection of information embedded in the epoch bit field {\ttfamily \doxylink{namespacevt_aebb04f13dc1ec6b4c3add2cd87295b13}{vt::\+\+Epoch\+Type}} that encodes the epoch type, category, scope, rank, etc.
