\doxysubsection{Detailed Description}
A description of the interval of interest for a modeled load query. 

The value of {\ttfamily \doxylink{structvt_1_1vrt_1_1collection_1_1balance_1_1_phase_offset_a8548a90b20b426e5986f20beb139d3d1}{phases}} can be in the past or future. Negative values represent a distance into the past, in which -\/1 is most recent. A value of 0 represents the immediate upcoming phase. Positive values represent more distant future phases.
