\doxysubsection{Detailed Description}
\doxylink{namespacevt_a492543313196079e88915c5b5b0072f8}{Active} receive broker that keeps a pool of pre-\/posted Irecv slots per size-\/class tag to drain unexpected \doxylink{structvt_1_1messaging_1_1_active_msg}{Active\+Msg} traffic quickly. 

Each completed slot dispatches directly to finish\+Pending\+Active\+Msg\+Async\+Recv and is immediately reposted with a fresh buffer of the same capacity.
