\doxysubsection{Detailed Description}
A VT component that backs the instrumentation of virtualized entities on each node, such as the objects that the collection manager orchestrates, to provide data to the load balancing framework. The actual instrumentation occurs in {\ttfamily vt::\+vrt:\+collection:\+}:\+balance::\+\+Element\+LBData which is composed into the elements of a collection. 

Collects LB data/\+timings on active function/\+methods for objects and communication between them on each node. After collecting this data, passes it to the load balancing framework, specifically the {\ttfamily \texorpdfstring{$\ast$}{*}} \doxylink{structvt_1_1vrt_1_1collection_1_1balance_1_1_l_b_manager}{vt::\+vrt::\+collection::\+balance::\+\+LBManager}
