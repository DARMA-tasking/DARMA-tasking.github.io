A core VT component that schedules work generated from other components. The pieces of work waiting to execute may be prioritized, see \doxylink{priority_8h}{src/\+vt/\+scheduler/\+priority.\+h}. 

Tracks work to be completed, orders it by priority, and executes it. Polls components for incoming work.
