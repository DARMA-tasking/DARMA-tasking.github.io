The base class for all messages. Common alias is {\ttfamily \doxylink{namespacevt_a2d5079028aeaeb60fd233ae4ae599af5}{vt::\+\+Message}} which uses the default envelope. 

This is templated over the envelope to allow longer or shorter messages to be used depending on the target and needed envelope bits.
