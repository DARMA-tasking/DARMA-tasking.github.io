\doxysubsection{Active Messenger }
\hypertarget{active-messenger}{}\label{active-messenger}\index{Active Messenger@{Active Messenger}}
Asynchronous send/\+receive of messages.

The active messenger {\ttfamily \doxylink{structvt_1_1messaging_1_1_active_messenger}{vt::\+messaging::\+\+Active\+Messenger}}, accessed via {\ttfamily \doxylink{namespacevt_aeafd31f866aeb4dc6fc2f6ee97136350}{vt::\+the\+Msg()}}, asynchronously sends and receives messages across nodes using MPI internally. When sending a message, it uses the {\bfseries{{\itshape vt}}} registry to consistently dispatch messages and data to handlers (function pointers, functors, or methods) across nodes.

Each message contains an envelope {\ttfamily \doxylink{namespacevt_a5c3a44320f11a37e50b92c191a9b7891}{vt::\+\+Envelope}} to store meta-\/data associated with the message, such as the destination and handler to trigger when it arrives. Sending a message entails setting up the envelope, optionally serializing the message (depending on whether the serialize overload is present), and then using {\ttfamily MPI\+\_\+\+Isend} to asynchronously transfer the bytes to the destination node. On the receive side, the active messenger is always probing for an incoming message and begins a transfer when it discovers one. The {\bfseries{{\itshape vt}}} \doxylink{scheduler}{Scheduler} polls the active messenger to make progress on any incoming messages.\hypertarget{active-messenger_am-simple-example}{}\doxysubsubsection{\texorpdfstring{Sending a message}{Sending a message}}\label{active-messenger_am-simple-example}
