Helper to unify \textquotesingle{}stealing\textquotesingle{} message ownership. 

This type is not intended to be used directly. It uses implicit conversion constructors to perform a \textquotesingle{}std::\+move\textquotesingle{} on a {\ttfamily \doxylink{namespacevt_a0f8ba6b65b1d630ab97265dcc90369a9}{Msg\+Ptr$<$\+Msg\+T$>$}\&}.

If a normal {\ttfamily Msg\+T\texorpdfstring{$\ast$}{*}} is supplied, it is promoted without stealing.
