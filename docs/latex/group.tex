\doxysubsection{Group Manager }
\hypertarget{group}{}\label{group}\index{Group Manager@{Group Manager}}
Create a grouping of nodes.

The group manager component {\ttfamily \doxylink{structvt_1_1group_1_1_group_manager}{vt::\+group::\+\+Group\+Manager}}, accessed via {\ttfamily \doxylink{namespacevt_a4548473dce44fb654400009e2b2fe64e}{vt::\+the\+Group()}} manages both rooted and collective groups (or subsets) of nodes that can be broadcast to or reduced over. The group manager implements a fully distributed algorithm for constructing groups collectively with each node deciding if it should be included. The group manager builds a reasonably balanced distributed spanning tree based on these collective votes.

One major use case for the group manager is creating spanning trees for reductions over virtual collections that do not span all the nodes.

When creating a group, one may ask {\bfseries{{\itshape vt}}} to create a underlying MPI group, which can be accessed once the group has finished construction.\hypertarget{group_collective-group-example}{}\doxysubsubsection{\texorpdfstring{Example creating a collective group}{Example creating a collective group}}\label{group_collective-group-example}
