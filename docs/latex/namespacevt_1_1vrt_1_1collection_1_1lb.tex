Recursive&Original strategy improved by recursion. When single object transfer is rejected, attempt to recurse in order to pull more objects into the transfer and hereby minimize work added by said transfer. This is especially useful when communication is taken into account, as object transfers typically disrupt local vs. global communication edges. \\

Swap\+Clusters&Form object clusters and attempt to perform swaps. Object can be clustered including to arbitrary definition, and swaps of entire clusters, including the nullset, between ranks are attempted. This is especially useful when shared memory constraints are present, as breaking shared memory clusters results in higher overall memory footprint, in contrast with whole cluster swaps. \\
