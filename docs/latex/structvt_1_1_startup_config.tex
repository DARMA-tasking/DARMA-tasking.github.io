Preconfigure VT with argc/\+argv. This will remove all VT arguments and create a {\ttfamily \doxylink{structvt_1_1_startup_config}{Startup\+Config}} for VT that should be passed to {\ttfamily initialize\+Preconfigured}. Optionally, one may specify an MPI communicator to use (otherwise, it defaults to {\ttfamily MPI\+\_\+\+COMM\+\_\+\+WORLD}). 

\begin{DoxyNote}{Note}
MPI must be initialized to call this function because if an error occurs it uses MPI rank to limit how many times the error text gets printed.
