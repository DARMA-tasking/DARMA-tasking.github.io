Initializes performance counters based on the {\ttfamily VT\+\_\+\+EVENTS} environment variable, which is a comma separated list of events available in the events header (\doxylink{example__events_8h}{example\+\_\+events.\+h} by default). Explicit groups may be provided with braces, such as {\ttfamily VT\+\_\+\+EVENTS="{}\{instructions,cycles\},cache\+\_\+misses"{}}. Append {\ttfamily !} to an event or explicit group to pin that group, such as {\ttfamily VT\+\_\+\+EVENTS="{}instructions!,\{cycles,cache\+\_\+misses\}!"{}}. If {\ttfamily VT\+\_\+\+PERF\+\_\+\+AUTO\+\_\+\+GROUP} is enabled, ungrouped events are bucketed using the descriptors from \doxylink{example__events_8h}{example\+\_\+events.\+h}. If {\ttfamily VT\+\_\+\+EVENTS} isn\textquotesingle{}t set, will default to measuring instructions.
