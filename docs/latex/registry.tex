\doxysubsection{Registry }
\hypertarget{registry}{}\label{registry}\index{Registry@{Registry}}
Registered handlers.


\begin{DoxyItemize}
\item The \doxylink{active-messenger}{Active Messenger} uses the registry to store/\+dispatch active function and active functor handlers.
\item The \doxylink{objgroup}{Object Group Manager} uses the registry to store/\+dispatch active member functions
\item The \doxylink{collection}{Virtual Context Collection} uses the registry to store/\+dispatch active functions with the object pointer and active members. 
\end{DoxyItemize}
